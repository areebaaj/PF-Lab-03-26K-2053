# Lab Title
Introduction to GitHub and C Programming

## Introduction

This lab introduces GitHub and basic concepts of the C programming language.
It focuses on creating and managing a GitHub repository, writing Markdown
documentation, and practicing basic C programming concepts.

## Objectives

1. Create and manage a GitHub repository.
2. Learn basic GitHub branches, commits, and pull requests.
3. Understand basic C data types and format specifiers.
4. Practice C input and output functions.
5. Learn precision and formatted output in C.

## C Topics Covered

- Data Types
- Format Specifiers
- Input/Output Functions
- Escape Sequences
- Precision
- Character Input and Output
- String Input
